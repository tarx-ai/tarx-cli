# Local-session preservation

The patches preserve the Oct 18 input repair and local personal alias. They contain source differences only, no credentials or memory. Do not apply them blindly to a different revision.

The installed private entry is /john, hidden from public help. It invokes the existing password gate; it is not product account authentication. Do not ship a hard-coded operator alias or founder access in the public client. Preserve the local launcher when upgrading; reconcile its patch explicitly. Never replace the local brain or terminate its running session as part of a public installer update.

Input contract: bracketed paste remains one message; Ctrl-G exits an incomplete paste without submitting; Ctrl-C cancels; IXON/IXOFF are disabled only while editing and terminal settings are restored. The public tarx source includes the input repair. Brain patch requires its separate owner to integrate. Windows portability work is on tarx/windows-ps1 and must be reconciled, not overwritten.

Known remaining gap: full-buffer redraw wraps physical lines; richer composer UI is not restored by this patch. A commit or patch is not an immutable lock: enforce regression tests and review release diffs.
